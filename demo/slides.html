Tech stack

Agent

  • Python 3.10–3.13 tool-use loop
  • Strands Agents as MCP client
  • Agent Skill: agentguard-billing

Models

  • Gemini via google-genai (live runs)
  • Amazon Bedrock provider + Strands BedrockModel
  • Bedrock: implemented, not yet run live

Tools and identity

  • MCP Python SDK 2.x
  • Streamable HTTP, naive :8001 / guarded :8002
  • Bearer-token identity, never tool arguments

Policy

  • YAML policy engine, all rules evaluated
  • Backend policies in plain Python
  • Decision receipts + safe alternatives

Proof

  • Runs: transcripts, receipts, state before/after
  • Trace exporter + damage scoreboard
  • GitHub Actions CI on 3.10–3.13

Experience

  • Alexa+ style web page
  • Web Speech API: voice in, spoken replies
  • Receipt card under every reply
